      📥 Import nodes from CSV / Excel
      Create many nodes and connections at once
      1 File 2 Columns 3 Preview
      One row per connection: node 1 name, node 1 type, connection, node 2 name, node 2 type. Without node 2 a standalone node is created.
      Optional columns (for node 1 or 2, e.g. url1, url2): url, platform, label, text, address, lat, lon, note. For the connection: arrows (-> <- <->), shape, color, line, width.
      Types: person, phone, email, username, social (or directly instagram, facebook, tiktok…), link, place, vehicle, text, target. If the type is missing it is guessed from the value.
      Drop the .csv / .xlsx file here or click to choose it
      Each column of the file can become a value of node 1, node 2 or the connection. “Extra field” columns go into the node's record under the column name, so no value of the file is lost.
      💰 Import Follow the Money
      Entities and relations from Aleph, OpenSanctions, ftm
      1 File 2 Filters 3 Import
      A Follow the Money entity file: JSON lines (one entity per line), a JSON array, or an Aleph export. Relation schemata become links, properties fill the fields of the matching type.
      FtM ids are kept: importing the same dataset again updates the nodes instead of duplicating them.
      Drop the .json / .jsonl / .ftm file here or click to choose it
      A Cognitor bundle (.cognitor.zip) carries the face photos and the transcripts: the photos become nodes linked to the persons, the transcripts join the sources.

      🎙 Transcribe a video
      Transcript, speakers and translation, all on this computer
      The video becomes a node with the transcript, every voice a person node “Speaker k” linked to the video by “speaks in”; the text joins the sources. Transcribing the same file again updates the same nodes. The models download once, on first use.
